# v1.01 发布说明

首个公开发布版（refactor/v2）。相对 v0.08 的主要变化：

- 语言：默认中文，英文可显式选择；界面文案全量资源化（1327 条键），相对时间中英各自正确。
- 上下文：伪无限上下文（热层原文 + 温层结构化摘要 + 冷层原文回捞），与插件自带压缩检查点共存。
- 稳定：崩溃落盘、设置快照环形 3 份、连续启动失败自动回滚、安全模式可一键退出；前台服务类型改 specialUse，不再触发 Android 15 的 dataSync 六小时超时崩溃。
- 插件：设置 schema 原生渲染、槽位限流与溢出菜单、失败可见（含 APK/dex、目录丢失、清单解析失败）、安全模式与加载失败分开表述。
- MCP：HTTP/SSE 服务器配置、测试连接、持久化，工具按 mcp__<server>__<tool> 注入，空闲回收后按需重连。
- 备份恢复：zip + manifest（分节勾选、版本比对、可选口令加密），旧格式包仍可整机还原。
- 身份卡：按轮次与卡变更注入，跨压缩续接不丢。

安装：`adb install -r HarnessForAndroid-release-v1.01.apk`；覆盖安装需与已装版本同证书（legacy 证书，SHA-256 见仓库 docs/signing.md）。
